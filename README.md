# Латинская анатомия

Офлайн-приложение (PWA) для изучения латинской анатомической терминологии.

Открыть: https://rusovezov33-code.github.io/latin-anatomy/

- Android (Chrome): ⋮ → «Добавить на главный экран».
- iPad / iPhone (Safari): «Поделиться» → «На экран «Домой»».

Прогресс хранится локально на каждом устройстве (localStorage); перенос — через экспорт/импорт в настройках.
При выпуске новой версии увеличьте `VERSION` в `sw.js`.
